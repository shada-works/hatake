# ちいさな畑

— Days on a Tiny Garden —

ちいさな畑で野菜を育てる のんびりゲームです。

## あそぶ

https://shada-works.github.io/hatake/

ホーム画面に追加しておくと、アプリのように すぐ開けます。

## あそびかた

- あいている畑をタップして、種をえらびます
- 水やりや収穫などは、1回30分。朝6時から 夕方6時まで 畑ですごします
- 「ひとやすみ」で ひと息、「1日を終える」で おうちへ
- 春・夏・秋・冬と 季節がめぐります（1つの季節は2日）
- とれた野菜で、おうちで料理。「にっき」で これまでの記録や 野菜図鑑が見られます

## 畑のたのしみ

- 季節ごとの野菜 24種類と、30品以上の料理
- 田んぼの田植え・稲刈り、果実の収穫
- なごみ度がたまると、おうちの中に ものが少しずつ ふえていきます
- 畑の曲と おうちの曲、効果音つき（右上の 音のボタンで切りかえ）

## セーブ

自動で保存されます。保存先は 遊んでいるブラウザの中なので、別の端末や 別のブラウザには 引きつがれません。
ブラウザのデータを消すと、セーブも消えるので ご注意ください。

## ファイル

`index.html` ひとつで できています（外部のライブラリや 画像ファイルは使っていません）。
