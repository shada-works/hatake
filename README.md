# ちいさな畑

— Days on a Tiny Garden —

ちいさな畑で 野菜を育てる のんびりゲームです。

## あそぶ

https://shada-works.github.io/hatake/

ホーム画面に追加しておくと、アプリのように すぐ開けます。

## あそびかた

- あいている畑をタップして、種をえらびます。たがやす・水やり・虫とり・収穫も、マスをタップするだけ
- 1回の作業は30分。朝6時から 夕方6時まで 畑ですごします
- 「ひとやすみ」で ひと息、「1日を終える」で おうちへ（やることが なくなると、自動で進みます）
- 春・夏・秋・冬と 季節がめぐります（1つの季節は2日）
- とれた野菜で、おうちで料理。「にっき」で これまでの記録や 野菜図鑑が見られます

## 畑のたのしみ

- 季節ごとの野菜 24種類（2年目・3年目に ふえます）と、130品以上の料理・デザート
- 果実の木、温室栽培、田んぼ、おじさんの おすそわけ
- 天候の変化、季節の行事
- なごみ度がたまると、おうちの中に ものが少しずつ ふえていきます
- 畑の曲（季節ごと）と おうちの曲、効果音つき（右上の 音のボタンで切りかえ）

## セーブ

行動のたびに 自動で保存されます（画面をとじるときにも 保存します）。保存先は 遊んでいるブラウザの中です。
別の端末や 別のブラウザに移すときは、「にっき」の「セーブの引き継ぎ」で コピーした文字を、移した先の「読みこむ…」に 貼りつけてください。
ブラウザのデータを消すと、セーブも消えるので ご注意ください。

## ファイル

`index.html` ひとつで できています（外部のライブラリや 画像・音のファイルは 使っていません）。
